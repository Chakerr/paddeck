# PadDeck

**ES** · Convierte cualquier pad numérico USB en un Stream Deck gratuito para OBS y atajos del sistema. Conecta el pad, presiona una tecla y asigna acciones desde una interfaz visual.

**EN** · Turn any USB numpad into a free Stream Deck for OBS and system shortcuts. Plug it in, press a key, and assign actions from a visual editor.

## Privacidad / Privacy

PadDeck solo procesa las teclas del pad que registras. No guarda ni envía pulsaciones de otros teclados y no tiene telemetría.

PadDeck only processes keys from the pad you register. It never stores or sends keystrokes from other keyboards and has no telemetry.
