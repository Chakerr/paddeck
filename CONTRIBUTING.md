# Contribuir / Contributing

¡Gracias por tu interés! / Thanks for your interest!

## Requisitos / Requirements
Windows 10/11, Rust (stable-msvc), Visual Studio Build Tools (C++), Node.js LTS.

## Flujo / Workflow
1. Abre un issue o comenta en uno existente antes de cambios grandes.
2. Crea una rama: `feat/...`, `fix/...`, `docs/...`.
3. Antes del PR: `cargo fmt --all`, `cargo clippy --all-targets -- -D warnings`, `cargo test`.
4. Commits con [Conventional Commits](https://www.conventionalcommits.org/).
5. Código y comentarios en inglés; textos de interfaz por i18n (`es`, `en`).

## Tu pad no funciona / Your pad doesn't work
Usa la plantilla de issue **"Mi pad no funciona"** e incluye modelo, VID/PID y versión de Windows. Así construimos la lista de compatibilidad.

## Buenas primeras tareas / Good first issues
Busca la etiqueta `good first issue`: traducciones, nuevas acciones, plantillas de perfiles.
